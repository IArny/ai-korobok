# 0.1.1 — 2026-11-20

## Fixed

- Persisted agent state restored files with wrong ownership. `tar --owner`
  and `--group` are creation-only flags that were silently ignored during
  extraction; `persist_push_to_guest` now scopes the restore to
  `/home/ubuntu` and runs `chown -R ubuntu:ubuntu` afterwards.
- VMs using the wifi-bridge network type now always get a NAT interface
  too, so they retain internet access alongside LAN connectivity.
